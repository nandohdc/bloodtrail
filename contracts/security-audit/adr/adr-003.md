## Decision

Opaque UUID event IDs, RFC 3339 UTC timestamps, zero-based retry attempts, 300 second skew alert threshold, and W3C trace/span as correlation-only context.

- Event ID remains stable on redelivery.
- Trace IDs are never identity or authorization evidence.
